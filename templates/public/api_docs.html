API 接口

RESTful 风格接口，返回 JSON

POST /api/v1/auth/register 无需认证

用户注册，注册成功后自动登录（若需审核则返回待审核状态）。

请求参数
参数类型必填说明
usernamestring是用户名，3-20字符
emailstring是邮箱地址
passwordstring是密码，至少6位
captchastring是图形验证码
invite_codestring条件邀请码（启用时必填）
响应示例 
{
  "code": 200,
  "message": "注册成功",
  "data": { "id": 2, "username": "testuser" }
}
错误码
400用户名、邮箱和密码不能为空
400验证码错误
400密码至少6位
409邮箱已被注册 / 用户名已被占用
429操作过于频繁，请稍后再试
POST /api/v1/auth/login 无需认证

用户登录，支持邮箱登录。

请求参数
参数类型必填说明
emailstring是邮箱地址
passwordstring是密码
响应示例 
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "id": 2, "username": "testuser", "nickname": "测试",
    "display_name": "测试", "email": "test@example.com",
    "avatar": "", "status": 0, "roles_id": [2],
    "created_at": "2025-01-01T12:00:00"
  }
}
错误码
400邮箱和密码不能为空
401邮箱或密码错误
403账号正在审核中 / 账号已被禁用
POST /api/v1/auth/logout 需要登录

退出登录。

响应示例 
{ "code": 200, "message": "已退出登录" }
GET /api/v1/auth/me 需要登录

获取当前登录用户信息。

响应示例 
{
  "code": 200,
  "data": {
    "id": 2, "username": "testuser", "nickname": "测试",
    "display_name": "测试", "email": "test@example.com",
    "phone": "", "avatar": "", "status": 0,
    "roles_id": [2], "created_at": "2025-01-01T12:00:00"
  }
}

用户模块

POST /api/v1/user/profile 需要登录

修改个人资料，只需传入需要修改的字段。

请求参数
参数类型必填说明
nicknamestring否昵称，最多30字符
emailstring否邮箱地址
phonestring否手机号
错误码
400昵称长度不能超过 30 个字符
409邮箱已被注册
POST /api/v1/user/password 需要登录

修改密码，成功后自动登出需重新登录。

请求参数
参数类型必填说明
old_passwordstring是旧密码
new_passwordstring是新密码，至少6位
错误码
400旧密码和新密码不能为空 / 新密码至少6位
401旧密码不正确
POST /api/v1/user/avatar 需要登录

上传头像。Content-Type: multipart/form-data

请求参数
参数类型必填说明
avatarfile是图片文件（png/jpg/jpeg/gif/webp/svg）

卡片模块

GET /api/v1/cards 无需认证

获取卡片列表，置顶优先、时间倒序。

查询参数
参数类型默认说明
pageint1页码
per_pageint12每页条数（最大50）
tagint—按标签ID筛选
响应示例 
{
  "code": 200,
  "data": {
    "items": [{
      "id": 1, "content": "...", "cover": "/uploads/...",
      "good": 5, "views": 100, "comments": 3,
      "is_top": 1, "author": "测试", "is_anonymous": false,
      "tags": [1, 2], "created_at": "2025-01-01T12:00:00"
    }],
    "page": 1, "pages": 5, "total": 48,
    "has_prev": false, "has_next": true
  }
}
GET /api/v1/cards/<card_id> 无需认证

获取卡片详情，每次访问浏览数 +1。登录用户可获取点赞状态。

POST /api/v1/cards 需要登录

发布卡片。Content-Type: multipart/form-data

请求参数
参数类型必填说明
contentstring是卡片内容，最多2000字符
is_anonymousstring否传 "1" 为匿名发布
tagsint[]否标签ID，可传多个
cover_filefile否封面图文件
imagesfile[]否附加图片，可传多个
POST /api/v1/cards/<card_id>/like 需要登录

点赞切换，已点赞则取消，未点赞则添加。

响应示例 
{ "code": 200, "data": { "liked": true, "count": 6 } }
POST /api/v1/cards/<card_id>/comments 需要登录

发表评论，最多500字符。

请求参数
参数类型必填说明
contentstring是评论内容

标签模块

响应示例
